# TIFFANY VILLA — Katameya Heights

Standalone bilingual Arabic/English premium property landing page for Tiffany Villa, developed by APIC. HTML/CSS/JS only; Vercel deploys from `main`.

## Source and accuracy

Project descriptions originate from archived APIC material (2022). Design images are 2022 conceptual renders from the user's Google Drive folder. Original TIFFANY identity references are 2023. These are not verified images of current property conditions. Pricing, inventory, contact information, delivery and payment plans require fresh approval before adding to the site.
